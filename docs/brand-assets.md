# TRANA logo used in the local pilot

15 November 2026. Jordi supplied `logo_trana_em (2) (1).tif` and requested use of the existing TRANA identity for now. The original file remains outside the repository.

- The complete logo is retained, including its lettering, proportions, texture and colours.
- `public/brand/trana-official.webp` is a 640 × 465 pixel web derivative, encoded as lossless WebP after proportional resizing. It retains transparency and is shown on white in the header and footer.
- `public/brand/trana-favicon.png` is a smaller proportional derivative for the browser icon.
- The header uses the complete official PNG derivative `public/brand/logo-trana-tif.png`; the footer uses the WebP derivative. Earlier unused fibre SVGs are kept outside the repository as local design references.
- Ownership remains with TRANA; the repository's code licence does not relicense the logo.

The desktop header places the complete logo, navigation/search and donation action in one row (about 146 px high at 1280 px wide). Mobile presents the donation and menu controls beside the logo; opening the menu reveals navigation and search. Contact details remain in the footer, with contact links inside the association menus in the local studies.

These changes are local only. The previous Cloudflare preview remains at the earlier deployed version until a separate deployment is requested.
