# Contributing

1. This repository is currently documentation only. Discuss changes to the pilot scope before adding an application or deployment automation.
2. Keep repository documentation in English and changes focused. TRANA's public content language is a separate editorial decision.
3. Describe technical findings without copying private correspondence, credentials, deploy-hook URLs or personal health information into public issues or commits.
4. Cite sources and distinguish observed API behavior from proposed implementation. Do not treat a successful content fetch as a completed accessibility or publishing test.
5. Contributions to this documentation use the license in [LICENSE.md](LICENSE.md). Confirm the code license before the first implementation commit; do not relicense TRANA or third-party content.
